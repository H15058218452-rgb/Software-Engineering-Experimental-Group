# 运行录屏脚本（照此录制，约 8~10 分钟）

工具：Win+G（Xbox Game Bar）或 PowerPoint「插入-屏幕录制」，分辨率 1920x1080，提前打开两个浏览器窗口（买家/卖家各一个，都指向 http://localhost:5173）。

| 段 | 时长 | 画面 | 操作与解说词 |
|---|---|---|---|
| 1 | 0:00-0:40 | 卖家端 | 打开登录页，解说"固定账号 seller 登录卖家后台"，登录成功 |
| 2 | 0:40-1:30 | 卖家端 | 发布商品：填名称"二手自行车"、价格 199.00、上传图片，提交后展示在售状态 |
| 3 | 1:30-2:20 | 买家端 | 匿名浏览商品详情，点购买，填张三/13800000001 提交，展示一次性口令码（强调只显示一次），再提交李四/13900000002，解说"先到先得排队" |
| 4 | 2:20-3:00 | 买家端 | 李四重复同手机号提交，提示 40904 重复提交；张三凭口令码查询位次、修改电话 |
| 5 | 3:00-3:40 | 卖家端 | 意向列表查看队列（按提交时间排序）；点"开始交易"，张三进入交易，商品显示交易中冻结 |
| 6 | 3:40-4:20 | 双端 | 卖家点解冻/下架均被拒（40908/40909 提示）；买家端购买按钮置灰提示"商品交易中"，张三无法撤销 |
| 7 | 4:20-5:20 | 卖家端 | 标记交易失败+作废张三：李四自动递补进入交易（强调商品未经过在售中间态）；再标记失败+李四重新排队：商品恢复在售 |
| 8 | 5:20-6:10 | 买家端 | 李四凭原口令码查询，状态"重新排队中"，口令码仍有效 |
| 9 | 6:10-7:00 | 卖家端 | 开始交易李四进入交易，标记交易成功：商品下架进入历史；打开历史商品看流水（张三已作废、李四成功） |
| 10 | 7:00-7:40 | 双端 | 买家端商品消失提示"暂无商品在售"；李四口令码查询提示失效（40905） |
| 11 | 7:40-8:20 | 命令行 | 运行 scripts/api-smoke-test.ps1 冒烟脚本，展示 14 步全部 PASS |
| 12 | 8:20-8:40 | 结尾 | 展示 Swagger 接口文档页 + GitHub 仓库页面 |

要点：每步操作前停顿 1~2 秒；报错提示处停留 3 秒让镜头看清错误码；口令码首次展示时用红框标注（可用画图工具）。
